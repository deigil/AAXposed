# v0.24#17.2-e2 (versionCode 3016, previous e1 / 3012)

- Fixed crash on car / DHU connect and immediate projection disconnect when "Hide head unit UI controls" is enabled.
- Fixed portrait apps being squeezed into a narrow centered strip on the head unit (new toggle "Force fullscreen for projected apps", enabled by default).
- Fixed occasional system soft reboots during projection (manifesting as launcher reload and killed apps).
- Adapted to the new LSPosed config channel so the module continues working on LSPosed 2.3.0.

Tested on: HyperOS `3.0.307.6` (Android 16) + Android Auto `17.3` + DHU; other devices / real head units untested. **Please reboot your phone after installing.** See [CHANGELOG.md](../../CHANGELOG.md) for technical details.
