# Release Notes v0.24 (17.2-e1)

Date: 2026-08-30
Version Name: `0.24#17.2-e1`
Version Code: `3012`
Baseline (initial erxm branch): `c770d65` — `release: v0.23.6 Android Auto 17.2 display hardening` (`0.23#17.2-r5` / `3011`)

## Overview

This release changes AADisplay from "head unit sidebar controls + fullscreen mirror window" to
**"head unit full-screen projection + phone MIUI-style floating window controls"**:

- Collapses the Coolwalk sidebar on the head unit so projection fills the full head unit width, without rebuilding control icons on the head unit;
- Turns the phone mirror window into a draggable, proportionally resizable floating window with touch pass-through outside the card;
- Fixes IME, eye-care mode, and Gboard floating keyboard issues affecting projection;
- Adds a standalone miuix-style settings page consolidating switches out of the menu.

Coolwalk facetbar code comes from `lagXkjy/AADisplay`'s `AADisplay-Split-Lite` branch via path-filtered cherry-pick from `reference`, preserving original authors and commit timestamps.

## Added

- **Coolwalk full-screen pipeline** (imported + locally adapted): collapses the head unit sidebar, reclaims rail width, and re-requests the projection canvas at full head unit width; adds settle retries when the rail appears late or is starved after soft reconnects.
- **`ICoreManager` Coolwalk rail channel**: gearhead cannot reliably deliver package-targeted broadcasts on Android 13+, so `:projection` / `:car` report rail snapshots to `CoreManagerService` in `system_server`, which broadcasts as system uid. 4 new methods appended at the end of the AIDL interface, preserving existing Stub ordinals:
  - `reportCoolwalkRailSnapshot` / `getCoolwalkRailSnapshot`
  - `getCoolwalkReconnectEpochMs` / `notifyCoolwalkFullBleed`
- **Icon mode for phone floating window recents panel**: `recent_task_icon.xml` shows only app icon + name.
- **Standalone settings page** `SettingsActivity` (miuix style, `pref_aadisplay_config.xml`).
- New config options:
  - `HideAaUiControls` (default `true`): hide head unit UI controls for Coolwalk full-screen; set `false` for legacy behavior (rebuild home/fullscreen/back/voice-assist icons in the head unit sidebar).
  - `SuspendEyeCareOnProjection` (default `true`)
  - `FixGboardFloatingIme` (default `true`)

## Changed

- Version bumped: `0.23#17.2-r5` / `3011` -> `0.24#17.2-e1` / `3012`.
- **Mirror window form**: previously full-screen with a scrim blocking outside touches. Now a `WRAP_CONTENT` `TYPE_APPLICATION_OVERLAY` floating window with `gravity = START|TOP` (`x`/`y` are absolute top-left offsets); touches outside the card pass through to the underlying app; top bar and bottom nav bar are drag handles; bottom-right handle drags to resize proportionally and long-presses to reset.
  Scaling uses a two-factor model `mDisplayRatio = mMirrorFitRatio * mMirrorScale`; `sv_mirror` touch forwarding divides by `mDisplayRatio`, so **all scaling changes must go through `updateDipslaySize()`** or touch targets will desync. `holder.setFixedSize()` pins the buffer at native head unit resolution so View scaling is pure GPU stretch without recreating the Surface.
- **`DisplayImePolicy` default changed from forced `0` (`DISPLAY_IME_POLICY_LOCAL`) to `1` (`DISPLAY_IME_POLICY_FALLBACK_DISPLAY`)**: keyboard falls back to the phone main screen instead of covering half the projection VirtualDisplay. Values are clamped to `0..2`, falling back to `1` if out of range.
- **`VoiceAssistShell` default** updated to XiaoAi (matching upstream nitsuya), supporting `${DisplayId}` placeholder.
- `XposedInit` dispatch updated: own process attaches `AaDisplayProcessHook`; Gboard process **only** attaches `GboardImeHook` — `OtherHook` zeroes `status_bar_height` for regular projected apps and should not alter the IME process.
- Main screen reorganized into cards; switches moved into the settings page.

## Fixed

- **Floating window recents panel overflowing card (reported as "misalignment")**: `ll_recent_task` was `match_parent` inside a `wrap_content` `FrameLayout`; during wrap measurement children received `AT_MOST`, and 9:16 snapshots in `recent_task.xml` stretched items taller than the head unit screen, overflowing the card over the nav bar.
  Fix: switch floating window to an icon grid without snapshots; write panel dimensions and grid column count at runtime in `updateRecentTaskPanelSize()` from `sv_mirror` pixels; pass `withSnapshot = false` to skip per-task `getTaskSnapshot` IPC and `HardwareBuffer` wrapping. Head unit `AaRecentTaskFragment` omits `iconMode` and keeps snapshot mode.
- **Projection turning yellow with eye-care mode**: MIUI/HyperOS eye-care is a SurfaceFlinger `colorTransformMatrix` on display 0 broadcast to all displays with no per-display exclusion. `EyeCareSuspender` temporarily disables `screen_paper_mode_enabled` during projection and restores it on disconnect. Trade-off: phone screen also loses eye-care during projection.
- **Gboard opening as floating keyboard during projection**: Gboard derives keyboard mode from persisted `keyboard_mode_landscape` / `float_keyboard_in_*` using device form factor (`DEVICE_PHONE`), so the landscape VD hits "phone + landscape". `GboardImeHook` overrides reads without writing any Gboard settings. Trade-off: phone landscape also won't float during projection.
- **`SharedPreferences` throwing `SecurityException` when LSPosed is inactive**: `PreferenceManager` only accepts one mode constant and throws inside `getSharedPreferences` where it cannot be caught. `resolveModeForHooks()` probes first and passes an available mode.
- **Media placeholder flashing on connect/reconnect** (imported with Coolwalk pipeline).

## Known Trade-offs

- Both `SuspendEyeCareOnProjection` and `FixGboardFloatingIme` suppress globally, affecting the phone itself during projection; both can be toggled off in settings.
- Head unit touch takeover (`AaCoolwalkHuTouchHook`) is **not** enabled or kept in tree: this branch uses the phone floating window for controls. See `reference/AADisplay-Split-Lite` if needed.
- Split-Lite's app picker, Bluetooth keyboard/mouse, and lyric/cover sync were **not** imported.
