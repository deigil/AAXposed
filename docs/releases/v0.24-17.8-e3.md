# v0.24#17.8-e3 (versionCode 3017, previous e2 / 3016)

## Android Auto 17.8 Adaptation

- Fixed "Hide head unit UI controls" breaking after upgrading to AA 17.8: 17.8 changed Compose's
  `Constraints` assertion message from `maxWidth must be >= than minWidth` to the formatted
  `maxWidth(%d) must be >= than minWidth(%d)`, causing the previous DexKit match to return 0 hits
  and silently disabling the guard (starving the container to negative height throws an assertion
  that kills `:projection`, crashing on car connect).
  Switched to the shared infix `must be >= than minWidth` for backwards compatibility.
- Fixed AADisplay not auto-opening on car connect: 17.8 removed `CarSystemUiControllerService`,
  so auto-open now uses AA's `ProjectionContext` singleton entry
  `startCarActivity(Intent, ActivityOptions)`, located precisely by DexKit using AA's own string
  constant instead of brittle obfuscated class names.

## Other Fixes

- Power key takeover adapted for HyperOS 3 / Android 16 (`powerPress` 3rd parameter became int);
  display power now uses `DisplayControl` physical display token, falling back to the legacy
  SurfaceControl path on failure.
- Unified virtual display teardown cleanup: releases adapter and VirtualDisplay even when
  `DisplayWindow` has not been created yet, preventing VD leaks and leftover shell hooks.
- Added root availability check and stage logging (exit code, truncated stdout/stderr) to
  `ShellManagerService`.
- Reduced floating window shadows (panel 6dp -> 3dp, mirror 12dp -> 4dp) with new `window_shadow_pad`
  to eliminate hard straight-line clipping at window bounds.
