# v0.24#17.8-e3（versionCode 3017，上一版 e2 / 3016）

## 适配 Android Auto 17.8

- 修复升级到 AA 17.8 后「隐藏车机 UI 控件」失效：17.8 把 Compose 的 `Constraints` 断言文案从
  `maxWidth must be >= than minWidth` 改成带格式符的
  `maxWidth(%d) must be >= than minWidth(%d)`，原来的 DexKit 匹配因此 0 命中，守卫静默失效
  （隐藏 UI 把容器饿到负高度时会抛断言打死 `:projection`，表现为连车闪退）。
  改用两版共有的中缀 `must be >= than minWidth` 匹配，向后兼容。
- 修复连车后不自动打开 AADisplay：17.8 删除了 `CarSystemUiControllerService`，
  auto-open 改走 AA 的 `ProjectionContext` 单例入口
  `startCarActivity(Intent, ActivityOptions)`，用 DexKit 按 AA 自身的字符串常量精确定位，
  不再依赖易变的混淆类名。

## 其它修复

- 电源键接管适配 HyperOS 3 / Android 16（`powerPress` 第三参变为 int）；
  显示电源改用 `DisplayControl` 的物理屏 token，失败时回落旧的 SurfaceControl 路径。
- 统一虚拟屏销毁清理路径：`DisplayWindow` 尚未建立时也会释放 adapter 与 VirtualDisplay，
  避免 VD 泄漏与销毁后的 shell 钩子残留。
- `ShellManagerService` 增加 root 可用性检查与阶段日志（退出码、截断的 stdout/stderr）。
- 悬浮窗阴影收窄（panel 6dp→3dp、mirror 12dp→4dp），配合新增 `window_shadow_pad`，
  消除被窗口边界切断的直线分界。

本版维持**单屏 + 手机端悬浮窗操作**路线，未引入分屏逻辑。

实测环境：HyperOS `3.0.307.6`（Android 16）+ Android Auto `17.8.663874` + DHU。
其他机型 / 真实车机未测试。**装完请重启手机。** 技术细节见 [CHANGELOG.md](../../CHANGELOG.md)。
